# The Global Biography of a Tube of Tretinoin

A socio-technical biography tracking a single tube of medicine from raw-material sourcing and generic manufacturing to informal transport, divergent national regulation, and disposal. This project explores how globalization is written into an everyday object.

## About This Project
A tube of medicine doesn't look like it has much of a story to tell. But the tube of 0.05% tretinoin ointment carried from India to Germany turned out to have a much longer history—one that runs through API production, generic manufacturing, national regulation, personal consumption, and eventually waste. 

This repository hosts a single-page HTML infographic that visually maps this journey across six stages, applying academic frameworks such as Commodity Chains, Global Value Chains, Political Economy, and the Linear Economy.
